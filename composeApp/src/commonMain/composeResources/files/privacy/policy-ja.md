# ものがたりパズル プライバシーポリシー

更新日：2026年10月5日
発効日：2026年10月5日
バージョン：1.0

## 1. 私たちについてと適用範囲

「ものがたりパズル」（以下「本アプリ」）は、子どもと保護者の一緒の読み聞かせのためのパズルアプリです。本ポリシーでは、個人情報の収集・利用・保存・保護の方法と、子どもと保護者の権利について説明します。

本アプリは Fancy2110 チーム（以下「私たち」）が運営しています。ご利用の前に、保護者の方がお子さまと一緒に本ポリシーをよく読み、ご理解いただいたうえで選択してください。

## 2. 収集する情報

パズルの基本機能にアカウント登録は必要ありません。基本機能の利用にあたって、名前、電話番号、写真の位置情報などの提供を求めることはありません。

保護者の方が「同意する」をタップした場合に限り、アプリの動作を把握するため、分析 SDK を通じて以下の匿名化・仮名化された情報を収集します。

- 端末情報：機種、OS バージョン、画面サイズ、端末の言語と地域
- 統計用の端末識別子（Android の端末識別子、iOS の IDFV など）。お子さまの本人と結びつけることはありません
- アプリ情報：アプリバージョン、通信の種類、ページの閲覧、ボタン操作、ゲームの開始、進捗と所要時間
- エラーと性能情報：クラッシュや読み込み時間（障害の調査に使用）

写真ライブラリ、連絡先、マイク、正確な位置情報、アプリ外での活動に関する情報は収集しません。本アプリに広告はなく、情報を広告配信に使用することもありません。

## 3. サードパーティ SDK

アプリの統計と動作監視のため、Umeng（友盟）分析 SDK（U-App）を使用します。

- 提供事業者：Umeng Tongxin (Beijing) Technology Co., Ltd.
- 利用目的：インストール数、利用状況、ページ閲覧、機能の利用、クラッシュの集計
- 収集情報：端末識別子、機種、OS、通信の種類、地域、アプリバージョン、操作イベント
- SDK のプライバシーポリシー：https://www.umeng.com/page/policy

この SDK は保護者の同意後にのみ初期化されます。同意されない場合でも、パズル機能は通常どおりご利用いただけます。

## 4. 情報の保存・共有・保護

分析情報は暗号化して送信し、安全なサーバー環境に保存します。保存期間は利用目的に必要な範囲内とし、期限後は削除または匿名化します。

子どもの個人情報を第三者に販売することはありません。法令で求められる場合、またはアプリの安全確保に必要な場合を除き、個人を特定できる情報を外部と共有することはありません。

アクセス管理や送信の暗号化など、合理的な措置を講じます。インターネット通信が絶対に安全ではないことをご理解ください。安全上の問題が発生した場合、法令に従って速やかにお知らせします。

## 5. 子どもの情報の特別な保護

本アプリは主に子どもを対象としています。私たちは最小限のデータ収集の原則に従い、以下をお約束します。

- 端末情報を収集する前に、保護者の明示的な同意を得ること
- パズルに関係のない個人情報を求めないこと
- 子どものプロファイル作成やターゲティング広告を行わないこと
- 保護者がいつでも同意を撤回でき、撤回後は新たな情報収集を停止すること

お子さまの情報の確認・訂正・削除、または取扱いへの拒否をご希望の場合は、本ポリシー末尾の連絡先までご連絡ください。ご本人確認のうえ、速やかに対応します。

## 6. あなたの権利

保護者の方には、以下の権利があります。

- 子どもの個人情報の取扱いについて知ること
- 情報を確認・訂正・削除すること
- 行った同意を撤回すること
- データの削除や取扱いルールの説明を求めること

これらの権利を行使されても、不利益な取扱いを受けることはありません。

## 7. ポリシーの更新

機能や情報の取扱いが変わる場合、本ポリシーを更新することがあります。収集する情報の種類の追加や新しい SDK の導入など重要な変更がある場合は、アプリ内で改めて保護者の同意を確認します。利用を継続された場合、更新後のポリシーに同意されたものとみなされます。
