# 故事拼图隐私政策

更新日期：2026年10月5日
生效日期：2026年10月5日
版本：1.0

## 一、我们是谁与适用范围

《故事拼图》（以下简称“本应用”）是一款面向儿童与亲子共读场景的拼图应用。本政策说明我们如何收集、使用、存储和保护个人信息，以及儿童与监护人享有的权利。

本应用的运营者为 Fancy2110 团队（以下简称“我们”）。在使用本应用前，请监护人陪同儿童仔细阅读本政策，并在充分理解后作出选择。

## 二、我们收集的信息

本应用的核心拼图功能不需要注册账号。我们不会因为基础功能要求儿童提供姓名、手机号、照片位置等信息。

仅在监护人点击“同意”后，我们才会通过统计分析 SDK 收集以下匿名或去标识化的信息，用于了解应用的运行情况：

- 设备信息：设备型号、操作系统版本、屏幕尺寸、设备语言与地区；
- 设备标识符：用于统计的设备标识（如 Android 设备标识、iOS 的 IDFV），不与儿童的真实身份关联；
- 应用信息：应用版本、网络类型、页面访问、按钮点击、游戏开始、完成进度与耗时；
- 错误与性能信息：崩溃、加载耗时等，用于排查故障。

我们不会收集相册、通讯录、麦克风、精确地理位置或儿童在应用之外的活动信息。本应用不包含广告，也不会将信息用于广告推送。

## 三、第三方 SDK

为完成应用统计与运行监控，我们使用友盟统计分析 SDK。

- SDK 名称：友盟统计分析 SDK（U-App）
- 提供方：友盟同欣（北京）科技有限公司
- 使用目的：统计安装量、活跃情况、页面访问、功能使用与崩溃情况
- 收集信息：设备标识符、设备型号、操作系统、网络类型、地区、应用版本及操作事件
- SDK 隐私政策：https://www.umeng.com/page/policy

该 SDK 仅在监护人同意后才会初始化。拒绝同意不会影响拼图功能的正常使用。

## 四、信息的存储、共享与保护

统计信息通过加密传输，并存储在安全的服务器环境中，保存期限不超过实现统计目的所必需的时间，到期后删除或匿名化处理。

我们不会向任何第三方出售儿童个人信息。除法律法规要求或为保障应用安全所必需的情形外，我们不会对外共享可识别个人身份的信息。

我们采用访问控制、传输加密等合理措施保护信息安全。请监护人理解，互联网传输并非绝对安全，如发生安全事件，我们将依法及时告知。

## 五、儿童个人信息特别保护

本应用主要面向儿童。我们遵循最小必要原则，并作出如下承诺：

- 在收集任何设备信息前，先取得监护人的明示同意；
- 不要求儿童提供与拼图无关的个人信息；
- 不基于儿童信息进行用户画像或精准营销；
- 监护人可以随时撤回同意。撤回后，我们将停止收集新的信息。

监护人如希望查询、更正或删除儿童的相关信息，或拒绝我们继续处理，可通过本政策末尾的联系方式与我们联系，我们将在核实身份后及时处理。

## 六、你的权利

监护人依法享有以下权利：

- 了解我们处理儿童个人信息的情况；
- 查询、更正或删除儿童的个人信息；
- 撤回已作出的同意；
- 注销相关数据或要求我们说明处理规则。

行使上述权利不会受到不合理差别对待。

## 七、政策更新

当功能或信息处理方式发生变化时，我们可能更新本政策。对于重大变更（如新增收集信息类型或新增 SDK），我们会在应用内再次征求监护人同意。继续使用即表示认可更新后的政策。

## 八、联系我们

如对本政策或儿童个人信息保护有任何疑问、意见或投诉，可通过以下方式联系我们：

- 电子邮箱：support@fancy2110.com
- 反馈时请注明“故事拼图隐私问题”

我们会在收到信息后尽快回复。
