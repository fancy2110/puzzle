# 故事拼圖隱私權政策

更新日期：2026年10月5日
生效日期：2026年10月5日
版本：1.0

## 一、我們是誰與適用範圍

《故事拼圖》（以下簡稱「本應用」）是一款面向兒童與親子共讀場景的拼圖應用。本政策說明我們如何收集、使用、儲存和保護個人資訊，以及兒童與監護人享有的權利。

本應用由 Fancy2110 團隊（以下簡稱「我們」）營運。使用本應用前，請監護人陪同兒童仔細閱讀本政策，並在充分理解後作出選擇。

## 二、我們收集的資訊

本應用的核心拼圖功能不需要註冊帳號。我們不會因為基礎功能要求兒童提供姓名、手機號、照片位置等資訊。

僅在監護人點擊「同意」後，我們才會透過統計分析 SDK 收集以下匿名或去識別化的資訊，用於了解應用的執行情況：

- 裝置資訊：裝置型號、作業系統版本、螢幕尺寸、裝置語言與地區；
- 裝置識別碼：用於統計的裝置識別（如 Android 裝置識別碼、iOS 的 IDFV），不與兒童的真實身分關聯；
- 應用資訊：應用版本、網路類型、頁面造訪、按鈕點擊、遊戲開始、完成進度與耗時；
- 錯誤與效能資訊：崩潰、載入耗時等，用於排查故障。

我們不會收集相簿、通訊錄、麥克風、精確地理位置或兒童在應用之外的活動資訊。本應用不包含廣告，也不會將資訊用於廣告推播。

## 三、第三方 SDK

為完成應用統計與執行監控，我們使用友盟統計分析 SDK。

- SDK 名稱：友盟統計分析 SDK（U-App）
- 提供方：友盟同欣（北京）科技有限公司
- 使用目的：統計安裝量、活躍情況、頁面造訪、功能使用與崩潰情況
- 收集資訊：裝置識別碼、裝置型號、作業系統、網路類型、地區、應用版本及操作事件
- SDK 隱私權政策：https://www.umeng.com/page/policy

該 SDK 僅在監護人同意後才會初始化。拒絕同意不會影響拼圖功能的正常使用。

## 四、資訊的儲存、共用與保護

統計資訊透過加密傳輸，並儲存在安全的伺服器環境中，保存期限不超過實現統計目的所必需的時間，到期後刪除或匿名化處理。

我們不會向任何第三方出售兒童個人資訊。除法律要求或為保障應用安全所必需的情形外，我們不會對外共用可識別個人身分的資訊。

我們採用存取控制、傳輸加密等合理措施保護資訊安全。請監护人理解，網際網路傳輸並非絕對安全，如發生安全事件，我們將依法及時告知。

## 五、兒童個人資訊特別保護

本应用主要面向兒童。我們遵循最小必要原則，並作出如下承諾：

- 在收集任何裝置資訊前，先取得監護人的明示同意；
- 不要求兒童提供與拼圖無關的個人資訊；
- 不基於兒童資訊進行使用者畫像或精準行銷；
- 監護人可以隨時撤回同意。撤回後，我們將停止收集新的資訊。

監護人如希望查詢、更正或刪除兒童的相關資訊，或拒絕我們繼續處理，可透過本政策末尾的聯絡方式與我們聯繫，我們將在核實身分後及時處理。

## 六、你的權利

監護人依法享有以下權利：

- 了解我們處理兒童個人資訊的情況；
- 查詢、更正或刪除兒童的個人資訊；
- 撤回已作出的同意；
- 請求刪除相關資料或要求我們說明處理規則。

行使上述權利不會受到不合理差別對待。

## 七、政策更新

當功能或資訊處理方式發生變化時，我們可能更新本政策。對於重大變更（如新增收集資訊類型或新增 SDK），我們會在應用內再次徵求監護人同意。繼續使用即表示認可更新後的政策。
