# 故事拼图 Fragma 组件化设计稿

这套设计稿从零开始建立设计语言，不生成 PNG。

## 文件结构

- `design-tokens.json`：颜色、字号、圆角、间距、组件尺寸。
- `components/*.svg`：独立设计素材，每个素材可单独打开和复用。
- `fragma-design-spec.html`：完整设计稿，类似 Figma 画板，用独立素材组合首页和拼图页。

## 画板

- 首页：`390 x 844` 基准，包含品牌区、5 页 Pager、碎片数量滑杆、主按钮、二级按钮。
- 拼图页：`390 x 844` 基准，包含返回键、进度牌、计时器、书页画布、候选碎片卷轴栏。

## 资源原则

- 背景、icon、按钮、插画、书页画布、候选栏全部使用 SVG。
- 设计稿内使用组件引用组合，避免将页面压成一张扁平图片。
- 后续工程实现应按 `design-tokens.json` 和组件尺寸映射到 Compose UI。
