# 故事拼图 V2 UI 标注

本文档用于约束当前 Compose 实现，目标对齐 `home-story-pager-concept.png` 与 `game-book-canvas-concept.png`。

## 全局

- 设计基准：移动端竖屏 390 x 844 pt，所有页面必须适配安全区。
- 背景：暖纸色渐变，顶部 `#FFFCF6`，中段 `#F7F2EA`，底部轻微青灰 `#EFF5F4`。
- 主文本：`#7A6750`，辅助文本 `#8F806E`，强调青绿 `#356D6A`，珊瑚主按钮 `#E98166`，金色装饰 `#CDA45A`。
- 圆角：主卡 28dp，图片内框 24dp，控制面板 26dp，按钮 24dp。
- 阴影：主卡 12-18dp，按钮/徽牌 8-10dp；阴影只用于层级，不用于大面积装饰。
- 图标：关键功能使用图形化图标或画布绘制，不使用大段文字替代。返回键、计时器、书本进度必须视觉可识别。

## 首页

### 顶部品牌区

- 安全区下方 18dp 页面边距。
- Logo：62 x 62dp，左对齐。
- 标题：`故事拼图`，38sp，粗体，青绿色。
- 副标题：14sp，辅助色，单行。
- 设置按钮：58 x 58dp，右对齐，使用齿轮符号/图标，云白底、米色描边。

### 故事 Pager

- 首页主视觉必须使用真正可滑动 pager，不只是左右按钮切换。
- Page 总数：5。
- 中央页：占可用宽度约 82%，左右各露出 9%-12% 邻页。
- Page 卡片：圆角 28dp，米色描边，纸张底色，轻阴影。
- 图片区域：卡内上半部分，内边距 10-14dp，圆角 24dp，裁切方式 `Crop`。
- 图片角饰：四角金色短线，不参与点击。
- 文案区：标题固定为 `画面故事`，左右分隔线和小圆点，故事正文居中，最多 3 行。
- 指示器：正文区下方居中，5 个点；当前点为青绿色宽胶囊，旁边显示 `n / 5`。
- 左右切换：可通过滑动完成；也可以保留两侧露出页点击快速切换。

### 碎片数量面板

- 面板高度约 118-132dp，圆角 26dp。
- 左上：拼图块符号 + `碎片数量`。
- 右上：浮雕数值胶囊，显示 `120片`。
- Slider：范围 10-300，连续选择，主轨青绿色，拇指珊瑚色。
- 刻度：10 / 80 / 150 / 220 / 300，水平等分。

### 操作按钮

- 主按钮：全宽，58dp 高，珊瑚色，文案 `开始拼图`，白色粗体。
- 次按钮：两列等宽，50dp 高，`换主题`、`换图片`。

## 拼图页

### 顶部控制

- 返回按钮：54 x 54dp，左上，云白底，米色描边，绘制明确左箭头。
- 进度徽牌：居中，高 54dp，显示书本图标 + `已拼 x/y`，左右金色点缀。
- 计时器：右上 86 x 54dp，绘制时钟图标 + `m:ss`。

### 画布/书页区域

- 棋盘整体为书本或画布台座，不能是普通矩形框。
- 外框：18dp 圆角，2dp 米色描边，18dp 阴影。
- 内部图片框：真实可放置区域，必须与拖拽命中坐标一致。
- 装饰：书脊线、金色角饰、底部台座阴影、右下书签；装饰不可改变真实图片区域坐标。
- 已放置碎片：只显示碎片内容，不显示整图。
- 高亮：拖拽区域重叠目标 50% 以上时，仅高亮目标碎片轮廓。

### 候选碎片栏

- 底部为卷轴容器，高 150dp，圆角 22dp。
- 左右卷轴柱、左侧书签装饰。
- 单个碎片卡 116dp 宽，圆角 14dp，米色描边。
- 选中态：青绿色半透明填充和 2dp 描边，不改变卡片尺寸，不能导致页面抖动。

### 底部提示

- 默认：`点击或拖动`，居中，12sp，辅助色。
- 选中碎片时：显示取消选择按钮，不挤压候选栏。
