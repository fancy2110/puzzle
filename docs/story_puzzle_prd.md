# 故事拼图 APP 产品需求文档

## 1. 产品概述

### 1.1 产品定位

故事拼图是一款面向儿童的叙事型拼图应用。产品通过将一个完整故事拆分为多个关键画面，让孩子按顺序完成每一幅画面的拼图，在观察、拼接、复盘的过程中理解故事情节、人物情绪和因果关系。

它不是单纯的“拼图小游戏”，而是一个将图像观察、空间推理、故事理解和亲子共读结合起来的儿童认知训练产品。

### 1.2 核心价值

- 对孩子：通过观察碎片、识别画面细节、还原故事场景，提升图像分析能力、专注力、空间感和叙事理解能力。
- 对家长：提供一个低压力、高参与感的亲子互动工具，让孩子在玩中阅读故事。
- 对内容方：将绘本、童话、原创故事转化为可交互体验，提升故事内容的参与深度和复玩价值。

### 1.3 一句话体验

孩子完成一幅幅故事画面拼图，每完成一幕，故事就向前推进一步，最终拼出一个完整故事。

## 2. 用户与场景

### 2.1 目标用户

核心用户：

- 3-8 岁儿童
- 已具备基础图形识别能力
- 喜欢绘本、拼图、动画故事或亲子共读

陪伴用户：

- 家长
- 幼儿园老师
- 儿童内容创作者

### 2.2 年龄分层

3-4 岁：

- 更适合 4-6 片大块拼图
- 故事情节应简单、画面元素清晰
- 需要较强提示和语音引导

5-6 岁：

- 适合 6-12 片拼图
- 可以理解简单因果关系
- 可加入观察提问，例如“谁在门口？”、“小熊为什么开心？”

7-8 岁：

- 适合 12-24 片拼图
- 可加入顺序推理、细节寻找和故事复述
- 可解锁更复杂的画面和多结局故事

### 2.3 典型使用场景

家庭睡前：

- 家长和孩子一起完成 3-5 幕短故事
- 每完成一幕读一句旁白
- 结束后引导孩子复述故事

碎片时间：

- 孩子单独完成一个故事章节
- 每关时长控制在 2-5 分钟
- 可暂停并继续

课堂活动：

- 老师选择一个故事
- 孩子分组完成不同画面
- 完成后按顺序讲述故事

## 3. 产品目标

### 3.1 体验目标

- 孩子能明确知道当前正在拼故事的哪一幕。
- 拼图过程有成就感，但不过度强调速度和竞争。
- 每一幅画面完成后，故事反馈清楚、温暖、有推进感。
- 整个体验像完成一本会动的绘本，而不是完成一组孤立拼图。

### 3.2 能力目标

产品希望训练以下能力：

- 图像观察：识别颜色、角色、物体、背景关系。
- 空间推理：通过边缘、纹理、内容连续性判断碎片位置。
- 故事理解：理解角色行为、场景变化、因果顺序。
- 语言表达：在完成后复述画面内容和故事发展。
- 专注与耐心：完成一个多步骤任务。

### 3.3 商业与增长目标

MVP 阶段不优先复杂商业化，重点验证：

- 孩子是否愿意完成多幕故事拼图。
- 家长是否认可教育价值。
- 故事内容是否能支撑复玩。

后续可扩展：

- 付费故事包
- 绘本 IP 合作
- 家长端成长报告
- AI 生成个性化故事
- 教师版课堂包

## 4. 核心产品机制

### 4.1 故事结构

一个故事由多个故事幕组成：

```text
故事 Story
  - 封面
  - 故事简介
  - 年龄建议
  - 难度建议
  - 故事幕列表 Scene[]

故事幕 Scene
  - 画面图片
  - 旁白文本
  - 拼图难度
  - 观察问题
  - 完成反馈
  - 下一幕入口
```

示例：

```text
故事：《小猫找月亮》

第 1 幕：小猫在窗边看见月亮
第 2 幕：小猫走进花园
第 3 幕：小猫遇到池塘里的月亮倒影
第 4 幕：妈妈告诉小猫真正的月亮在天上
第 5 幕：小猫和妈妈一起看月亮
```

### 4.2 拼图与叙事关系

每一幕都不是随便选一张图，而是故事理解的关键节点。

孩子需要通过拼图完成：

- 场景识别：这是哪里？
- 角色识别：谁在画面里？
- 动作识别：角色正在做什么？
- 情绪识别：角色开心、害怕、疑惑还是惊喜？
- 情节推进：这一幕和上一幕有什么关系？

### 4.3 难度控制

难度不只由碎片数量决定，还包括：

- 碎片形状复杂度
- 画面细节密度
- 相似色块比例
- 是否显示参考图
- 是否自动吸附
- 是否提供边缘提示
- 是否分阶段释放碎片

建议难度：

| 难度 | 年龄 | 碎片数 | 参考图 | 提示 |
| --- | --- | --- | --- | --- |
| 启蒙 | 3-4 | 4-6 | 常驻显示 | 强提示 |
| 基础 | 5-6 | 6-12 | 可开关 | 中提示 |
| 进阶 | 7-8 | 12-24 | 可短暂查看 | 弱提示 |
| 挑战 | 8+ | 24+ | 无常驻 | 少提示 |

## 5. 核心用户流程

### 5.1 首次进入

```text
启动 APP
  -> 品牌启动页
  -> 选择故事
  -> 查看故事封面和简介
  -> 选择难度 / 使用推荐难度
  -> 开始第 1 幕
```

### 5.2 单幕拼图流程

```text
进入故事幕
  -> 播放/显示本幕开场旁白
  -> 展示完整画面 2-3 秒
  -> 画面碎裂为拼图
  -> 孩子拖拽/点击碎片完成拼接
  -> 完成后高亮整幅画面
  -> 播放完成反馈
  -> 提出观察问题
  -> 进入下一幕
```

### 5.3 完整故事完成流程

```text
完成最后一幕
  -> 显示故事完成庆祝
  -> 回顾全部故事画面
  -> 孩子按顺序浏览每一幕
  -> 可听完整故事朗读
  -> 可进入“我来讲故事”复述模式
  -> 返回故事书架 / 再玩一次
```

## 6. 页面设计需求

### 6.1 故事书架页

目标：

让孩子和家长选择要体验的故事。

核心元素：

- 故事卡片
- 封面图
- 故事标题
- 年龄建议
- 预计时长
- 进度状态
- 是否已完成

交互：

- 点击故事卡进入故事详情。
- 已完成故事显示完成标记。
- 未完成故事显示“继续第 N 幕”。
- 支持按年龄、主题、时长筛选，MVP 可先不做筛选。

### 6.2 故事详情页

目标：

让家长理解故事内容，让孩子产生期待。

核心元素：

- 大封面
- 故事标题
- 简短简介
- 故事幕数量
- 推荐年龄
- 推荐难度
- 开始按钮
- 继续按钮

交互：

- 点击开始后进入第 1 幕。
- 若有进度，优先显示继续。
- 家长可调整难度。

### 6.3 故事地图页

目标：

展示故事进度，让孩子知道自己正在完成一个连续故事。

核心元素：

- 横向或路径式故事进度
- 每一幕的小缩略图
- 当前幕高亮
- 已完成幕点亮
- 未完成幕锁定或灰显

交互：

- 已完成幕可回看。
- 当前幕可开始。
- 未完成幕不可直接跳过，除非家长开启自由模式。

MVP 可选：

- 可先用“第 1 幕 / 共 5 幕”的顶部进度替代完整地图。

### 6.4 拼图游玩页

目标：

完成当前故事幕的拼图，同时保持故事上下文。

核心元素：

- 顶部：返回、当前幕标题、故事进度
- 中央：拼图区域
- 底部：碎片候选区
- 辅助：参考图、提示按钮、旁白按钮

交互：

- 拖拽碎片到正确区域。
- 若碎片覆盖目标区域 50% 以上，高亮目标碎片区域。
- 放置正确后吸附并显示碎片内容。
- 放置错误时温和反馈，不惩罚。
- 可点击碎片选中，再点击目标区域放置，照顾低龄儿童。
- 可暂停。

状态：

- 准备中
- 拼图中
- 正确放置
- 错误尝试
- 单幕完成
- 暂停

### 6.5 单幕完成页

目标：

让孩子理解“刚刚拼出的画面发生了什么”。

核心元素：

- 完整画面
- 本幕旁白
- 观察问题
- 下一幕按钮

交互：

- 点击画面可查看细节。
- 点击旁白按钮可重听。
- 回答观察问题可获得轻反馈。
- 点击下一幕进入下一幅画。

观察问题示例：

- “小猫看到了什么？”
- “画面里谁在笑？”
- “你觉得它下一步会去哪里？”

### 6.6 故事完成页

目标：

强化完整故事体验和成就感。

核心元素：

- 完成庆祝动画
- 全部故事幕缩略图
- 故事标题
- 完成时间
- “听完整故事”
- “我来讲故事”
- “再玩一次”
- “换个故事”

交互：

- 点击缩略图回看某一幕。
- 点击听完整故事，按顺序播放旁白。
- 点击我来讲故事，进入复述模式。

### 6.7 家长设置页

目标：

让家长管理难度、提示、音效和内容。

核心元素：

- 年龄档位
- 默认难度
- 是否显示参考图
- 是否开启语音旁白
- 是否开启完成后问题
- 每日游玩时长提醒
- 内容管理入口

MVP 可做：

- 音效开关
- 参考图开关
- 默认难度

## 7. 内容设计规范

### 7.1 故事要求

每个故事建议：

- 3-7 幕
- 单幕画面表达明确
- 每幕只讲一个关键动作或情绪
- 故事情节有开始、发展、转折、解决
- 角色数量不宜过多

### 7.2 画面要求

适合拼图的画面应满足：

- 主体明确
- 色块有区分度
- 背景不过度复杂
- 每个关键角色或物体有可识别轮廓
- 避免大面积纯色导致拼图困难
- 避免细节太碎导致低龄儿童挫败

### 7.3 旁白要求

旁白应短、清楚、可被孩子复述。

建议格式：

```text
第 1 幕旁白：
晚上，小猫坐在窗边，看见天上有一个圆圆的月亮。

完成反馈：
你拼出了小猫看到月亮的画面！

观察问题：
小猫在哪里看月亮？
```

### 7.4 问题设计

问题分三类：

- 观察型：画面里有什么？
- 理解型：角色为什么这样做？
- 预测型：接下来可能发生什么？

MVP 建议优先做观察型和简单理解型。

## 8. 游戏机制需求

### 8.1 拼图生成

当前 APP 已具备图片切割和拖拽拼接能力。故事拼图方向需要补充：

- 按故事幕加载不同图片。
- 每一幕生成独立拼图。
- 每一幕完成后保存进度。
- 支持同一故事中不同幕使用不同难度。
- 支持不规则碎片，增强观察与辨识。

### 8.2 成功判定

单个碎片：

- 拖拽到目标区域且重叠比例大于等于 50% 时，高亮。
- 松手后若目标正确，吸附到正确位置。
- 若目标错误，碎片回到候选区或停留在当前位置后提示。

单幕完成：

- 所有碎片均正确放置。
- 显示完整画面。
- 进入本幕完成反馈。

故事完成：

- 所有故事幕均完成。
- 进入故事完成页。

### 8.3 提示机制

提示应鼓励观察，而不是直接代替孩子完成。

提示等级：

1. 显示完整参考图 3 秒
2. 高亮一个目标区域
3. 高亮一个碎片边缘
4. 自动放置一个碎片，MVP 不建议默认开启

### 8.4 错误反馈

原则：

- 不使用失败、扣分、刺耳音效。
- 使用温和反馈，例如“再看看颜色和边缘”。
- 多次失败后自动给提示。

规则：

- 连续 3 次错误，弹出轻提示。
- 连续 5 次错误，建议查看参考图。

## 13. 关键风险与对策

### 13.1 故事感不足

风险：

如果每幕只是孤立图片，孩子会觉得是在做普通拼图。

对策：

- 每幕完成后必须有旁白和故事推进。
- 顶部持续显示故事进度。
- 完成后提供整段故事回顾。

### 13.2 拼图太难导致挫败

风险：

碎片太多、画面太复杂会让低龄儿童放弃。

对策：

- 根据年龄默认难度。
- 保留参考图。
- 连续错误后自动提示。
- 大块碎片优先。

### 13.3 教育感过重

风险：

如果问题太像考试，会破坏游戏感。

对策：

- 问题以对话形式出现。
- 不强制答题。
- 不显示对错分数。
- 使用鼓励式反馈。

### 13.4 内容生产成本高

风险：

多幕故事需要多张一致风格画面，制作成本高。

对策：

- MVP 先做少量高质量内置故事。
- 后续接入 AI 辅助生成草稿。
- 建立画面规范和故事模板。

## 14. 当前工程改造建议

基于当前 APP 已有能力，建议按以下顺序改造：

### 阶段一：故事数据层

- 新增 `Story`、`StoryScene`、`StoryProgress` 数据模型。
- 新增本地故事资源目录。
- 将当前单图主题改为故事幕图片来源。
- 支持按 scene 启动拼图。

### 阶段二：导航与页面

- 新增故事书架页。
- 新增故事详情页。
- 新增单幕完成页。
- 新增故事完成回顾页。
- 当前首页可改造为故事书架。

### 阶段三：游戏流程

- 当前 `GameViewModel` 增加 story/session 状态。
- 每完成一幕后不直接结束，而是进入幕完成状态。
- 点击下一幕后加载下一张 scene 图片并重新切割。
- 完成最后一幕后进入 story completed。

### 阶段四：内容与体验

- 设计第一个内置故事。
- 为每幕配置图片、旁白、问题。
- 加入语音/音效反馈。
- 增加进度保存。

## 15. 第一个内置故事建议

### 故事名

《小星星回家》

### 目标年龄

4-7 岁

### 故事主题

勇气、观察、帮助别人

### 故事幕

第 1 幕：夜晚，小星星掉到了森林里。

- 观察点：星星、树、月亮
- 问题：小星星在哪里？

第 2 幕：小兔发现了发光的小星星。

- 观察点：小兔、草地、星光
- 问题：谁找到了小星星？

第 3 幕：小兔和小鸟一起想办法。

- 观察点：两位朋友、树枝、天空
- 问题：它们想帮小星星做什么？

第 4 幕：大家搭起高高的云梯。

- 观察点：云梯、朋友们、天空
- 问题：云梯通向哪里？

第 5 幕：小星星回到了夜空，照亮森林。

- 观察点：星空、森林、朋友们
- 问题：小星星回家后，森林变得怎么样？

## 16. 结论

故事拼图方向具备明确的产品价值：它将拼图从单一空间游戏升级为叙事理解工具。孩子不是为了完成一张图而拼图，而是为了推动故事继续发生而拼图。

当前工程已经具备图片切割、碎片拖拽、完成判定和跨端基础能力，下一步重点不在底层拼图算法，而在“故事结构、幕间流程、内容数据、完成反馈”四个方面。

建议先用 1 个高质量 5 幕故事完成 MVP，验证孩子是否愿意连续完成多幕拼图，以及家长是否认可这种“拼图式绘本”的教育价值。
